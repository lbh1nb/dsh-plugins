# dsh-file-explorer

DeepSeek Harness Web 插件：右侧边文件管理器。

- 可折叠右侧浮层面板（`shell.overlay`），贴边「文件」标签开关
- IDE 级目录树：紧凑行高、展开/收起、按扩展名着色的文件图标、选中高亮
- 内嵌预览：文本（≤256KB，可编辑保存）、图片（≤2MB，base64 预览）
- 文件操作：新建文件/文件夹、重命名（行内编辑）、删除（二次确认）、刷新
- 安全：所有路径解析后强制落在工作区根内（防目录穿越），同源 POST 校验
- 二次元彩蛋：空目录时小仙鹤报喜（AI 生图，水墨风）

安装方法见仓库根 [README](../../README.md)。
