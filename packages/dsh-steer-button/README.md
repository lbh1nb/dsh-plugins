# dsh-steer-button

DeepSeek Harness Web 插件：输入框「插话」按钮 —— 中途纠偏不用记快捷键。

- 常驻输入框工具行右侧（`conversation.input.right`）。
- 空闲时灰色；agent 运行中自动激活，点击即把草稿以 steer 模式注入当前轮次（等同 Ctrl/Cmd+Enter），成功后自动清空草稿。
- 反馈：点击后显示 ✓/⚠ 提示；忙碌时图标呼吸动画。

图标由 Trae（AI IDE）生成（深灰举手小人 + 橙色对话气泡），经透明抠图与像素级小尺寸验收后内联为 20px base64。

安装方法见仓库根 [README](../../README.md)。
